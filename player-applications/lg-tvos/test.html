myNextScreen — postMessage Test

This page simulates the LG app's postMessage flow for testing in a browser.

Open it from file://. The player only accepts a handoff from its own origin or from an opaque one ('null'), which is what the webOS shell has — serving this page over http from another port gets the message ignored, exactly as it should be.

The player pairs itself, so there is no key to send: after the handoff it shows a six-digit code to enter in the dashboard.
