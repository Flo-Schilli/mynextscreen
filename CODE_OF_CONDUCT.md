# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help. Criticise code, not people.

## What is expected

- Keep discussion technical and specific. "This breaks X because Y" is useful;
  "this is terrible" is not.
- Accept that a maintainer may decline a change without owing a long
  justification. A small project cannot carry every idea.
- Respect that people contribute in their spare time, across time zones and
  languages.

## What is not acceptable

Harassment, personal attacks, discrimination, sexualised language or imagery,
publishing someone's private information, and sustained disruption of
discussions.

## Scope

This applies in the repository — issues, pull requests, discussions and commit
messages — and anywhere someone is representing the project.

## Enforcement

Report a problem through a private security advisory on this repository, or by
contacting the maintainer directly. Reports are handled confidentially.

The maintainer may edit or delete contributions, and block accounts, when this
document is violated. For a first, minor incident that will usually be a note
asking for a change in tone.
